# OAMS Field App — React Native (Expo) · v2

Store-recce field app built in **React Native (Expo SDK 51)**.

## Flow (v2)
1. **Login** — Employee Code + Password, mode **Deployment / Recce** (Recce is live; Deployment later)
2. **Store List** — search & select a store
3. **Store Recce** screen:
   - **Store Photos** — upload from different angles, **minimum 5** (camera or gallery) + **remark**
   - **Elements** — for each: *what is it* (Sunboard / Art Board / …), *surface*, **Width × Height**,
     **2 photos WITHOUT mark + 2 photos WITH mark**, and a **remark**
   - **Final remark**
4. **Submit → PPT** — a PowerPoint with every photo + all details + remarks (built by the backend)

## Run / edit live
```bash
cd oams-rn
npm install
npx expo start        # scan QR with Expo Go, or press "a" for Android
```
Edit any file in `src/` and save → app hot-reloads.

## Key files to edit
| What | File |
|---|---|
| Colors | `src/theme.js` |
| Element types / surfaces / stores (offline) | `src/data.js` |
| Backend URL | `src/config.js` |
| Screens | `src/screens/*.js` |
| Element form (2+2 photos) | `src/components/ElementEntryModal.js` |

## Backend (PPT + real data)
The PPT report is generated by `../oams-backend` (PptxGenJS). To connect:
1. `cd ../oams-backend && npm install && npm start`
2. In `src/config.js` set `API_BASE`:
   - Android emulator: `http://10.0.2.2:4000/api`
   - Real phone (same WiFi): `http://<your-PC-IP>:4000/api`
3. Login `EMP1024 / 1234`. The installed APK already allows http (cleartext) for LAN.

## Build the APK
GitHub Actions builds a small **arm64 release APK** on every push and publishes it to
the GitHub Release `oams-rn-latest`.
