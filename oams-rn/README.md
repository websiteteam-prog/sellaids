# OAMS Field App — React Native (Expo)

The same OAMS field-ops app, rebuilt in **React Native (Expo SDK 51)**.
Real camera (expo-image-picker), real GPS (expo-location), file save/share
(expo-file-system + expo-sharing), and a PPT report generated by the backend.

> Standalone/offline by default (bundled demo data in `src/data.js`).
> Set `src/config.js` → `API_BASE` to connect to the `oams-backend` server.

## Screens
Login → Configuring → Welcome → Home → Ticket List → Ticket Detail (GPS gate)
→ Store Overview (camera + items) → Save → PPT report.

## Run in development
```bash
cd oams-rn
npm install
npx expo start          # scan the QR with the Expo Go app, or press "a" for Android
```

## Build the APK
Built automatically by GitHub Actions (`.github/workflows/build-rn-apk.yml`)
on every push — the APK is uploaded as an artifact and committed to
`dist-rn/oams-field-app-rn-debug.apk`.

### Build locally (needs Android SDK + Java 17)
```bash
cd oams-rn
npm install
npx expo prebuild --platform android --no-install
cd android && ./gradlew assembleDebug
# APK -> android/app/build/outputs/apk/debug/app-debug.apk
```

## Connect to the backend
1. Start the demo backend: `cd ../oams-backend && npm install && npm start`
2. In `src/config.js` set `API_BASE`:
   - Android emulator: `http://10.0.2.2:4000/api`
   - Real phone (same WiFi): `http://<your-PC-LAN-IP>:4000/api`
   - Hosted: `https://your-server.com/api`
3. Rebuild the APK (push to the branch).
